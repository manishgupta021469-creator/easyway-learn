Easyway Learn v56 Render build fix

This package keeps the v55 speech + OCR changes and fixes the Render Docker build failure.

Root cause found in Render logs:
- Docker build failed during apt-get install because the Dockerfile requested `fonts-deva-core`.
- Debian Bookworm provides the Devanagari font meta-package as `fonts-deva`; the font is not required by the OCR pipeline anyway.

v56 Dockerfile installs only the required OCR/PDF packages:
- tesseract-ocr (includes English data)
- tesseract-ocr-hin (Hindi data)
- poppler-utils (PDF page rendering)

Upload/replace these files at the repository root:
- app.js
- server.js
- Dockerfile

Then commit once. Render should auto-deploy.
