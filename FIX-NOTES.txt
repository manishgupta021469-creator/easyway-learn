Easyway Learn V67 — OCR Definitive / Clean Root Package

What was fixed in one pass:
1. OCR routes are defined only once, before authentication. The old duplicate authenticated /api/ocr and /api/ocr-batch handlers were removed.
2. Browser OCR upload uses a dedicated stateless fetch that does NOT attach the Student session token. Expired login cannot produce "Authentication required" for OCR.
3. Added no-cache OCR requests and OPTIONS handling.
4. OCR supports English + Hindi, image and PDF input, with Tesseract PSM 6/3/11 candidates.
5. PDF pages are rendered page-by-page with Poppler.
6. OCR chapter and paragraph detection remains enabled.
7. Raised bounded OCR request/file limits for real textbook PDFs.
8. Clean deployment package: no database files, WAL/SHM, PID or server logs are included.
9. Service-worker cache bumped to v67.
10. Docker installs Tesseract English/Hindi and Poppler without the failing fonts-deva-core package.

IMPORTANT:
Copy these files directly into the Render-connected repository ROOT (not inside a v67pkg folder), then commit all files together.

Verification endpoint after deploy: open /api/ocr-status on the same Render URL. It should return ok:true and show eng:true, hin:true.
